HOW TO USE

랜덤 팀을 나누는 방법

참가자 이름과 팀 수만 입력하면 별도 설치 없이 바로 무작위 팀 배정 결과를 만들 수 있습니다.

01
참가자 입력

이름을 한 줄에 한 명씩 입력하거나 쉼표로 구분합니다.

02
팀 수 설정

만들고 싶은 팀의 개수를 2~20 사이에서 선택합니다.

03
랜덤 팀 생성

참가자를 무작위로 섞고 각 팀에 순환 방식으로 배정합니다.

04
결과 확인

팀별 명단을 확인하고 다시 섞거나 결과를 복사합니다.

ALLOCATION

팀 인원은 가능한 한 균등하게 배정됩니다

참가자 목록을 먼저 무작위로 섞은 뒤 A팀부터 마지막 팀까지 한 명씩 순서대로 배정합니다. 참가자 수가 팀 수로 정확히 나누어지지 않는 경우에도 팀별 인원 차이는 최대한 작게 유지됩니다.

FAQ

자주 묻는 질문

같은 이름을 여러 번 입력하면 어떻게 되나요?

앞뒤 공백과 대소문자를 무시하고 같은 이름으로 판단되는 항목은 한 번만 사용합니다.

팀마다 인원 수가 완전히 같아지나요?

참가자 수가 팀 수로 나누어떨어지면 같아집니다. 나누어떨어지지 않으면 일부 팀에 한 명이 더 배정될 수 있습니다.

입력한 이름이나 결과가 서버에 저장되나요?

아니요. 팀 생성은 브라우저 안에서 처리되며 최근 기록은 현재 브라우저의 localStorage에만 저장됩니다.

같은 참가자로 다시 랜덤 배정할 수 있나요?

네. 결과 상단의 다시 섞기 버튼을 누르면 동일한 참가자와 팀 수로 새로운 배정 결과를 만들 수 있습니다.
