HOW TO USE

랜덤 번호를 뽑는 방법

원하는 숫자 범위와 개수를 입력하면 별도 설치 없이 브라우저에서 바로 랜덤 번호를 만들 수 있습니다. 중복 번호가 필요하면 중복 허용 옵션을 켜면 됩니다.

01
최대 숫자 입력

1부터 최대 999까지 사용할 숫자 범위를 설정합니다.

02
뽑을 개수 입력

한 번에 몇 개의 번호를 생성할지 입력합니다.

03
중복 여부 선택

같은 숫자의 반복 추첨이 필요하면 중복 허용을 켭니다.

04
결과 활용

생성 결과를 다시 뽑거나 복사하고 최근 기록에서 확인합니다.

RANDOM LOGIC

중복 허용 여부에 따라 추첨 방식이 달라집니다

중복 허용을 켠 경우 각 번호를 독립적으로 생성합니다. 중복을 허용하지 않는 경우 1부터 최대 숫자까지의 목록을 무작위로 섞은 뒤 필요한 개수만큼 선택하므로 한 번의 추첨 안에서 같은 번호가 반복되지 않습니다.

FAQ

자주 묻는 질문

최대 숫자는 몇까지 설정할 수 있나요?

현재 웹툴에서는 1부터 999까지 설정할 수 있습니다.

중복 없이 뽑을 때 개수가 최대 숫자보다 많으면 어떻게 되나요?

중복 없는 추첨에서는 가능한 숫자의 수보다 더 많이 뽑을 수 없기 때문에 오류 메시지를 표시합니다.

추첨 기록은 어디에 저장되나요?

최근 기록은 서버가 아닌 현재 브라우저의 localStorage에만 저장됩니다. 브라우저 데이터를 지우면 기록도 삭제될 수 있습니다.

같은 조건으로 다시 추첨할 수 있나요?

네. 결과의 ‘다시 뽑기’를 누르거나 최근 기록에서 ‘재사용’을 누르면 같은 조건을 다시 적용할 수 있습니다.
