사용 방법

1순서를 변경할 PDF 파일을 선택합니다.
2페이지 카드를 드래그해 원하는 순서로 이동합니다.
3필요한 경우 페이지를 맨 앞으로, 맨 뒤로 보내거나 삭제합니다.
4변경된 PDF 저장 버튼을 눌러 새 파일을 다운로드합니다.

브라우저에서 처리

✓선택한 PDF 자체는 JCraft Studio 서버로 업로드하지 않고 현재 브라우저에서 처리합니다.
✓원본 파일은 변경하지 않고 새 PDF를 생성합니다.

큰 PDF 안내

!페이지 수가 많거나 용량이 큰 PDF는 미리보기 생성과 저장에 시간이 더 걸릴 수 있습니다.

PDF 페이지 순서 변경 방법

설치 프로그램 없이 웹 브라우저에서 PDF의 페이지 순서를 변경할 수 있습니다. 원본 파일은 그대로 유지되고 변경된 순서로 새 PDF 파일이 생성됩니다.

01

PDF 선택

순서를 바꿀 PDF 파일을 선택하거나 업로드 영역에 끌어다 놓습니다.

02

페이지 확인

PDF의 각 페이지가 미리보기 카드 형태로 표시됩니다.

03

순서 재배치

페이지를 드래그하거나 앞·뒤 이동 버튼을 사용해 순서를 정리합니다.

04

새 PDF 저장

현재 순서대로 새 PDF를 만들어 기기에 저장합니다.

자주 묻는 질문

아니요. PDF 파일은 브라우저에서 읽고 처리하며 선택한 PDF 자체를 JCraft Studio 서버로 전송하지 않습니다.
네. 각 페이지 카드의 삭제 버튼을 누르면 해당 페이지를 결과 PDF에서 제외할 수 있습니다. 단 최소 1페이지는 남아 있어야 합니다.
원본 파일은 변경하지 않습니다. 변경한 순서대로 별도의 새 PDF 파일이 생성됩니다.
가능하지만 파일 크기와 페이지 수가 많을수록 브라우저 메모리 사용량이 증가하고 미리보기 및 저장 시간이 길어질 수 있습니다.
