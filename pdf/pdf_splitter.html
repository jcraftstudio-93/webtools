PDF 파일을 분할하는 방법

별도의 프로그램을 설치하지 않고 PDF 문서를 원하는 페이지 범위별로 나눌 수 있습니다.

02
범위 입력

PRIVACY

PDF 파일을 별도 서버에 업로드하지 않습니다

이 도구는 선택한 PDF를 사용자의 브라우저 내부에서 처리하도록 구성되어 있습니다. 파일 크기와 페이지 수가 매우 많으면 사용 기기의 브라우저 메모리 한계로 처리 속도가 느려지거나 작업이 실패할 수 있습니다.

FAQ

자주 묻는 질문

페이지 범위는 어떻게 입력하나요?

1-3, 4-6, 8처럼 입력하세요. 쉼표로 구분한 각 항목이 하나의 결과 PDF가 됩니다.

모든 페이지를 한 장씩 나눌 수 있나요?

네. 모든 페이지 개별 분할을 선택하면 각 페이지가 별도의 PDF 파일로 생성됩니다.

암호로 잠긴 PDF도 분할할 수 있나요?

현재 버전은 암호가 해제된 PDF를 기준으로 동작합니다. 암호화된 파일은 브라우저 라이브러리에서 열지 못할 수 있습니다.

모바일에서도 사용할 수 있나요?

최신 모바일 브라우저에서도 이용할 수 있습니다. 다만 페이지 수가 많은 PDF는 기기의 메모리 제한에 영향을 받을 수 있습니다.
