사용 방법

별도 프로그램 설치 없이 세 단계로 ZIP 파일을 만들 수 있습니다.

1

파일 선택

압축할 파일을 여러 개 선택하거나 드래그 앤 드롭으로 추가합니다.

2

파일 이름 설정

다운로드할 ZIP 파일 이름을 입력합니다. 확장자는 자동으로 붙습니다.

3

압축 및 다운로드

ZIP 만들기를 누르면 브라우저에서 압축한 뒤 결과 파일을 자동으로 다운로드합니다.

자주 묻는 질문

선택한 파일이 서버로 업로드되나요?

아니요. 이 도구는 브라우저의 파일 처리 기능을 사용하며 선택한 파일 자체를 JCraft Studio 서버로 전송하지 않습니다.

왜 큰 파일은 제한하나요?

웹 브라우저에서 ZIP 파일을 만들 때 메모리를 사용하기 때문입니다. 500MB를 넘으면 경고하고, 1GB 초과 또는 1,000개 초과는 브라우저가 멈추거나 종료될 가능성을 줄이기 위해 차단합니다.

압축하면 항상 파일 크기가 크게 줄어드나요?

그렇지 않습니다. JPG, MP4, ZIP처럼 이미 압축된 형식은 ZIP으로 다시 묶어도 크기가 거의 줄지 않을 수 있습니다. 이 도구는 여러 파일을 하나의 ZIP 파일로 묶는 용도로도 사용할 수 있습니다.

최근 생성 기록에서 ZIP 파일을 다시 받을 수 있나요?

같은 페이지를 열어 둔 현재 세션에서는 생성한 ZIP을 다시 다운로드할 수 있습니다. 페이지를 새로고침하거나 브라우저를 종료한 뒤에는 기록 정보만 남으며 ZIP 데이터 자체는 저장하지 않습니다.
